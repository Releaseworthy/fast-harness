# D42: Tool, agent and command files

Owner, 2026-11-12: "tao muốn mọi thứ đều custom và chỉnh sửa được" (docs/efficiency-plan.md phase 17A part 2, `docs/extending.md`; G1 "G1 theo plan"). `tools/*.json` with a `command` is a command tool (`tools::CommandTool`: JSON arguments on stdin, stdout the result under the D37 budget, non-zero exit an error with the stderr tail, the process tree in one `ProcessGroup` killed on timeout or cancel); without `command` it overrides the built-in of that name (`description`, `outputBytes` into `toolOutput` unless set there, `disabled`). `agents/*.md` and `commands/*.md`: front matter `name`, `description`, `model`, `effort`, `tools`, `maxDepth` and a body (`config::index::read_md`). The index (`config::index::ExtIndex::build`) lists the three folders of every trusted layer and reads only names and descriptions, cached in `~/.fast-harness/index.json` by path, size and modified time (nanoseconds); no file in any folder: `index.json` is not opened. `tools::Extensions` (in `AgentParts::extensions`, built in `Runtime::apply`) builds every registry of a session: built-ins with overrides, subagent tools, then command tools; the list is frozen per session (D36). A subagent `agent` names an agent type: its body opens the child's first user message (system unchanged, prefix shared), its model, effort and tools apply unless the call sets them, its `maxDepth` only lowers the setting; `find_tools` names the types (under 1 KB, "and n more"; no text added without types). `/name args` in the TUI, GUI and `-p` (`app::slash`): `$ARGUMENTS` replaced or the args appended; `/help` lists the built-ins and the files. `tools.preload` (empty by default) preloads tools in a top-level session with the D40 synthetic find pair. `fast-harness doctor` lists tools, agents and commands; GUI Settings > Configuration lists every key with value and source and opens the config folder.
