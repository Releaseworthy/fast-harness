# D31: System prompt editing

Owner, 2026-11-12: "cho phép thay đổi system prompt", global plus per workspace. The prompt text is a template with `{cwd}`, `{os}`, `{date}` and `{model}`: `~/.fast-harness/system-prompt.md` for every workspace, `~/.fast-harness/prompts/<cwd slug>.md` for one workspace (it wins); without a file the built-in default (D18) applies. The AGENTS.md section (D12) is still appended and the OAuth identity block stays first for Claude subscription. GUI: Settings > System prompt edits the global prompt or the selected workspace's override, with Reset to default and a live preview of the rendered prompt; a change applies to new sessions, and running sessions get a note (D36; an unreadable file falls back to the next source with a note).
