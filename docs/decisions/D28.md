# D28: Workspaces

Owner, 2026-11-12: "thêm cả workspaces bên trái nữa (tạo hình folder icon nha)". The sidebar lists WORKSPACES: each row a folder icon (an open folder for the current one) and the folder name (the full path on hover); a click selects it and expands its sessions, newest first; New session starts in the selected workspace; `+` adds a folder through the Windows "Select folder" dialog (IFileOpenDialog through windows-sys, on its own thread); a hover `x` removes it from the list only. Kept in `~/.fast-harness/workspaces.json` (version 1), seeded on first run with every folder that already has sessions plus the window's folder.
