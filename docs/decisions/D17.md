# D17: Live model catalog

Owner, 2026-11-11: fetch Claude's newest models and effort levels each time the user opens the model or effort picker. `GET /v1/models` (all pages, retired models left out) gives per model `capabilities.effort` levels and `capabilities.thinking.types`; a process-wide registry (`llm::anthropic::remember_models`) holds them, filled by every successful list and by `models.json` at start. `efforts` and `fit_effort` read it before the table; the request builder reads it only for models missing from the table (adaptive, budget or no thinking as the API says). Front ends call `Runtime::models()` then `ModelSource::fetch` off the UI thread; `cached()` gives the last known list or the table. A failed list never holds or switches the account. CLI: `fast-harness models [--json]`.
