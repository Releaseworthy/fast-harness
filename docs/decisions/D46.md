# D46: Panels

Owner, 2026-11-12: "ui plugin thì bắt buộc người dùng phải build lại hả" (docs/efficiency-plan.md phase 21A, G4: panels need no build; `docs/panels.md`). `panels/*.json` `{"id","title","icon","where":"tab"|"sidebar","command","args"}` in the user folder and a trusted project folder (`panels::load`, read in `load_settings`, kept in `Runtime::panels`; later layer wins per id). No process before a panel opens (Settings > Configuration `panels.<id>` rows with "Open", `/panel <id>` in GUI and TUI); `panels::Process` runs the command in one `ProcessGroup` with writer, stdout, stderr and waiter threads and a `Wake` callback, killed on app exit; a dead process shows `process ended (exit code N): <last stderr line>`. JSON lines: host `init`, `click`, `submit`, `change`, `session` (subscribed `turn`, `tool`, `usage`); process `view`, `patch`, `subscribe`, `notify`. `panels::flatten` turns the tree into `Row { depth, cells }` (unknown widget: a `note` cell). GUI: one panel view on the "panel" page (tab and sidebar panels both open there) with one `for` over one row component (`ui/panel_view.slint`, no `if`, no std widget; parts shown by `look` through `visible`, text, marks and click actions decided in `src/panels.rs`), one widget per row, table lines joined by tabs, a select click picks the next option. Exe cost (budget 150 KB): `if` per widget with std ListView, Dropdown, KeyInput +1,293,312 bytes; primitives with `if` +974,848; one cell component +591,872; one row component +368,128; Rust-side text and actions +328,192 (the shipped design). Owner, 2026-11-12: "chỉ 320kb thôi, chấp nhận được, thậm chí 600kb cũng chấp nhận được, size của file exe không quan trọng bằng goal là harness gui chạy nhẹ tài nguyên ram,cpu,gpu": the +328,192 byte delta is accepted; the GUI budgets are RAM, CPU and GPU use (idle and with a panel, `docs/perf.md` phase 21A), exe size is secondary. TUI: `tui/panel_screen.rs` text with Tab, Enter, Left, Right, Esc.
