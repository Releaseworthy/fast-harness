# D90: reads keep their room, the log knows old sessions' files, agent_output says once (2026-11-15)

The owner's retest of D87 and D88 in his real session (`20261115-053943-38a0`, subagent logs `20261115-090201-3cf8/3cf9`) found three remaining costs.

- Read size. Each read gave about 3 KB (87 short or 24 wide lines), and an explicit `limit 64` gave 58 lines. The cause was the D84 step share, not the read head: a step of 4 calls left a read 16 KB / 4 = 4 KB less 1 KB note room, one of 6 calls left 2,730 B less 682 B. Now a `read` keeps its own budget (`toolOutput.read`, else 8 KB) in any step (`ContextConfig::call_budget`) and still counts toward the other calls' shares. The note room is 512 B (the notes take under 300). The read head is 7 KB, so a plain read returns about 6.5 KB of lines and a ranged one about 7.5 KB.
- Edit after reopen. The edits refused as "not read in this session" (log lines 280 and 329) came from sessions started before `<id>.files.json` existed: the old binary kept the state only in memory, and a reopen on the new binary had nothing to load. After a reopen on the new binary the edit was taken (log line 376). Now a file `files.json` lacks falls back to the session log (`agent/logged_files.rs`). The file must appear in a successful `read`, `write` or `edit` call there, its path resolved like the tools do and canonicalised. It counts as known at its current content when its modified time is not after that call's result time, and is refused naming the call otherwise.
- agent_output twice. A repeated `agent_output` for an answer a call already returned sent it again (3,981 B, log line 380). Each background child now records where its answer reached the context, either `call <id>` or the finished notice. A repeat returns `[already returned in call <id>]`. A compaction forgets these places (`children::forget_delivered`), as it clears read ranges, so the answer can be fetched whole again.

Tests: `tests/read_room.rs` (the owner's 58-of-64 and 87-line numbers), `tests/file_state_resume.rs` (a log without `files.json`, and a file modified after it), `tests/subagents.rs` `agent_output_names_the_call_that_already_returned_the_answer`, `tests/agent_output_compact.rs`.
