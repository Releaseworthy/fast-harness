# D57: Plugin API hardening: types

Owner, 2026-11-13 (docs/architecture-plan.md gate G9, "Harden now and call it unstable for 0.x"). The plugin API is unstable for every 0.x release (docs/plugins.md, "Stability"). Rule: every struct with public fields and every enum `ext::v1` reaches is `#[non_exhaustive]` and re-exported from `v1`; plugins and other crates build structs with constructors and match enums with a wildcard (front ends: an unknown value is ignored or fails safe); a method added to `Tool`, `Provider`, `Hook`, `Panel` or `Transport` has a default body. Structs: `ToolSpec`, `ChatRequest`, `Cache`, `Timing`, `Completion`, `LlmError`, `ProviderFile`, `ModelFile`, `Price`, `CompactionPatch`, `Host`, `Answer`, `ToolCtx`, `ToolOutput`, `ToolSession`, `Message`, `Usage`, `HttpRequest`, `HttpHead`, `HttpError`. Enums: `AgentEvent`, `TurnOutcome`, `Auth`, `Delta`, `ErrorKind`, `Incoming`, `Place`, `HookEvent`, `Effect`, `Role`, `Block`, `StopReason`, `Flow`, `HttpErrorKind`. Variants keep exhaustive fields. `[[plugin]]` may carry `api = 1` (or `"1"`, JSON `"api": 1`; absent is 1); another value fails `build.rs` and `apply-plugins.ts`; a test keeps the three copies of the number equal. Serde output unchanged.
