# D15: Themes

`fast_harness_core::theme`: Dark (default), Light, Greyscale dark, Greyscale light (theme list superseded by D33), shared by the TUI and the GUI. Tests hold every theme to WCAG 2.2 (7:1 body text, 4.5:1 other text, 3:1 borders and focus) and APCA Bronze (Lc 75 body, 60 other text); greyscale themes are pure greys for text and background; status colours always come with a mark or a word. The pick is saved as `theme` in `config.json`. The GUI draws its own widgets (`ui/widgets.slint`) because the Slint std-widgets palette is read only.
