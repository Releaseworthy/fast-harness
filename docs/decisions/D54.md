# D54: Tool effects and run order

Owner, 2026-11-12 (docs/architecture-plan.md gate G5, "By effect"). `Tool::effect()` is `Read`, `Write` or `Run` (default); `Tool::parallel()` defaults to `effect == Read`. read, grep, glob, find_tools, mcp_describe, agent_output, sessions_list, session_read: Read; write, edit: Write; the rest Run, `subagent` parallel (D40). A step's calls run in order: consecutive parallel calls together, any other alone after all before it; a cancel turns unstarted calls into `cancelled before it ran`. `tools/*.json` takes `"effect"`. write and edit replace files through a temp file and a rename (in-place write if that fails).
