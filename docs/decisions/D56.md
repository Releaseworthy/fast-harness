# D56: Accounts under the store lock

Owner, 2026-11-12 (docs/architecture-plan.md gate G6). `accounts.json` stays version 3. Every change is `AccountStore::update`: under the store lock it reloads the file, applies the delta, writes it with `store::write_atomic`. A refresh holds the lock (30 s wait, above the 12 s OAuth timeout) and uses the refresh token on disk; a usable pair another process stored is taken without a call. Before a lease or a status a file changed on disk (length, modified time) is reloaded. A failed write keeps a refreshed pair in memory, retries on the next pool call and shows as `AuthSource::warning` (once per turn). Holds, forced and dead stay per process.
