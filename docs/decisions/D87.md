# D87: Reads and edits answer with what the model needs next

Owner, 2026-11-15 (five items on `read` and `edit`).

1. A `read` whose `offset` is past the end of a file the session already read answered `[unchanged since call …]` (a range read to the end covers every later line number). It now fails like the first read of the file: `offset N is past the end of the file (M lines)` (`read::unchanged_inside`).
2. A re-read after the session's own `edit` answered `[unchanged since call …]`: the edit moved the read ranges along, so a forgotten newline that merged two lines stayed unseen. Now an `edit` keeps the ranges at the version they were read at and records it in `file_state::Snapshot::base`; the next `read` diffs that version against the file (the D6 changed-lines answer, `read_diff`) and returns the lines the edits changed. A read that does not show the diff moves the untouched ranges to the new version and drops the touched ones. `write` still makes the whole file known. `edit` checks only the content hash, so it is unaffected.
3. `context.readHeadBytes` defaults to 6 KB (was 4 KB). D83 chose 4 KB from a cost model (a byte at mid-turn against one extra step) and said itself that whether a real model takes extra steps after a head was not measured; the owner saw ~64 lines (~2.4 KB of lines after the 1 KB note room) and more read calls. 6 KB leaves ~5 KB of lines; a crowded step still caps each call at its share.
4. A read overlapping earlier reads ends with a range line for the whole request (`[lines 50 to 80 of 300; continue with offset 81]`, `[lines 280 to 300 of 300]` at the end), after the `[already shown …]` notes; a result cut by the budget names the request's first line to the last line shown.
5. `edit` with an `old_string` not found names the most similar lines (`edit_hint::nearest`: per-line character-pair likeness over a window of as many lines as `old_string`, at least 50 %, up to 8 lines shown numbered; skipped over 1,000,000 line pairs). Several matches name the line of each (first 10).

Tests: `tests/read_edit_notes.rs` (one per item, each failed before), `tests/file_tools.rs` and `tests/context_diet.rs` updated.
