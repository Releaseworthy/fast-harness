# D41: Settings layers and provider files

Owner, 2026-11-12: "tao muốn mọi thứ đều custom và chỉnh sửa được" (docs/efficiency-plan.md phase 17A, part 1; `docs/extending.md`). Layers, later wins key by key: built-in defaults, `~/.fast-harness/config.json`, `<project>/.fast-harness/config.json`, environment, command line (`--model`, `--effort`); `config::layers::load` keeps the source of every dotted key (`Layered::get`). The project is the nearest folder at or above the working directory holding a `.fast-harness` folder other than the home; it loads only when trusted (`~/.fast-harness/trusted.json` `{"version":1,"paths":[canonical paths]}`, `fast-harness trust [PATH]`, `/trust` in the TUI and the GUI); untrusted, nothing of it loads and the first agent of each front end carries the note once (TUI and GUI note, print `[note]` on stderr). A bad user `config.json` is still an error; a bad project file or provider file is skipped and reported. `config::layers::kind_files(layers, kind, ext)` is the one lister of extension files (user folder, then the trusted project folder, each sorted by name; no folder, no work), used by `providers/` now and by tools, agents and commands next. `providers/*.json`: `{"id","name"?,"api":"anthropic-messages"|"openai-chat","baseUrl","keyEnv"|"account":"claude","headers","models":[{"id","name"?,"contextWindow","maxOutput","efforts","price":{"input","output","cacheRead","cacheWrite","cacheWrite1h"} per million tokens,"compaction","cache"}]}`; a later file with the same id replaces the earlier one; models are `<id>/<model id>` in pickers, config, traces and `fast-harness models`; a file with id `anthropic` or `antigravity` only overrides built-in models (window, maxOutput caps the request `max_tokens`, price, compaction joins `models` unless config.json has that exact entry). Registry `llm::custom` (process-wide, merged by id, never shrinks within a process). `openai-chat` (`llm::openai`): `POST {baseUrl}/chat/completions`, `stream: true`, `stream_options.include_usage`, bearer key unless empty, file headers; tools as functions, only `find_tools` plus found tools (D30, as on Antigravity); streamed `tool_calls` arguments; `reasoning_content` shown as thinking and never sent back; `prompt_tokens_details.cached_tokens` (or `prompt_cache_hit_tokens`) is the cache read; `reasoning_effort` only for an effort the entry lists; 400/413 with context-length wording is `ContextOverflow`. `stats` adds `costMicroUsd` and `pricedSteps` for models with a price: cacheRead defaults to input, a 5 minute write to cacheWrite else input, a 1 hour write to cacheWrite1h else twice input. `fast-harness config path|get KEY|set KEY VALUE [--project]`, `fast-harness doctor`. A child takes its parent session's frozen system (`Children::system`, set at turn start), also after a resume.
