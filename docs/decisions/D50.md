# D50: Memory and reflect

Owner, 2026-11-12: "tao muốn mọi thứ đều custom và chỉnh sửa được" (docs/efficiency-plan.md phase 20, `docs/extending.md` "Memory"). `agent::memory`: `<app home>/memory/<cwd slug>/MEMORY.md` (index, one line per note, `MAX_INDEX_BYTES` 2048) and `notes/*.md`; no memory tool, the block names the folder and the model uses `read`, `write`, `edit`, `grep` (they take absolute paths, no path policy blocks it). `Context::system` = `stable_system()` + `\n\n<memory_index>\n...\n</memory_index>` (`"memory": false` drops it); the whole text is the frozen session system (D36), so a resume replays it; `stamp.memory` (hash of MEMORY.md) gives a `[context update] The memory index ... changed` note, never for a stamp without the key. `llm::split_memory` cuts the block back off: Claude sends it as its own system block after the stable one, both with the system TTL (1h under `auto`); with a memory block the OAuth identity block has no breakpoint, so a request has 4: last loaded tool, stable block, memory block, last user block (the stable block's breakpoint covers the identity); without one the layout is unchanged. Antigravity and OpenAI send the text whole (stable part, then the block). Compaction (`remember_facts`, top-level sessions only) appends the `Durable facts` section to `notes/compaction-facts.md` under `## <date>` and sets its index line; over 2 KB the oldest lines move to `notes/index-archive.md`, whose line goes first. `stats::signals`: repeated reads (by path), `not loaded yet` errors, failed edits (`edit`/`write` errors), non-zero shell exits by program, most steps of a turn, cache rewrites (a later step whose cache write is at least its read), next to the D35 numbers. `reflect`: `digest` (per turn steps, tool calls, result bytes, error first lines of 120 chars; no user, assistant or result text), `pick_model` (`reflect.model`, else the cheapest `price` input+output of `providers/*.json`, else the session model), `extract_diff`, `patch` (unified diff; `memory/<path>` is the memory folder, other paths relative to cwd; absolute and `..` refused; all checked before any write). `Runtime::reflect_job(cwd, id, args)` prepares on the caller's thread and runs one tool-less turn (system `reflect::SYSTEM`) in a child session log; the diff is kept as `<id>.reflect.diff`. `"selfImprove"`: `ask` (default, applies nothing; `/reflect apply` or `fast-harness reflect --apply`), `auto` (memory files only), `off` (refused). TUI and GUI run `/reflect [apply]` on a thread and show the text as a note; print mode and `serve` do not handle `/reflect`. Nothing runs at turn end. Other memory systems plug in through `Stop` and `PreCompact` hooks (D44).
