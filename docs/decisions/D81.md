# D81: ask_user_question and the session popup

Owner requests, 2026-11-14. Core: the tool `ask_user_question` (`tools/ask.rs`), deferred like every tool but `find_tools` (D30). Input `{questions: [{id, header?, question, options?: [{label, description?, recommended?}], multi_select?}]}`, 1 to 4 questions, 0 to 6 options; a label ending in "(Recommended)" (suffix dropped) or `recommended: true` marks the recommended option, moved first. Effect `Run` (it blocks on the user, so it never runs alongside other calls, D54) and exempt from the approval gate (D64).
- The wait reuses the session's `Gate` (`agent/approval/ask.rs`): `AgentEvent::QuestionRequest(QuestionRequest {id, call_id, questions, agent})`, then `QuestionDone {id, answer}` with `answered`, `skipped`, `cancelled` or `paused`; live only. `Session::set_asking(true)` marks a front end that answers, `Session::questions()`, `Session::reply(id, Option<Vec<QuestionAnswer>>)` (`None`: skipped). Stop, pause and close end the wait (`cancelled before it ran`, a paused text).
- Nobody answering (print mode, `serve`, the TUI for now): the tool runs and returns `no user is available to answer ...` at once (`ask::NO_USER`).
- Result: `The user answered:` then `- <id> (<question>): "<label>", ..., custom answer: "<text>"` per question.
- GUI: one popup (`ui/popup.slint`) at the bottom of the chat column, the composer's width, over the composer (hidden while it shows), for both approvals (`ui/approval.slint`, keys unchanged) and questions (`ui/ask.slint`, `src/ask.rs`): radio or check marks, the recommended option first with the lightning icon and the word "Recommended" (also in the accessible label), descriptions dim, always a last "Other…" row with a text box (typing chooses it), several questions stacked, scrolling past 60% of the window; Up/Down, Space, Tab, Enter submits, Esc skips. The chat keeps its frame: the transcript's rows end above the popup (`TranscriptView.pad` = popup height plus the gaps; a ListView takes no child after its `for`, so the pad is cut from the list's height) and stay at the bottom while following.
- Left: GUI software-window tests of the popup geometry and focus, the screenshots, a TUI prompt.
