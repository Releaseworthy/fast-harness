# D47: MCP, lazy

Owner, 2026-11-12: "tao muốn mọi thứ đều custom và chỉnh sửa được" and D30 (find first, every provider) (docs/efficiency-plan.md phase 18, `docs/extending.md`). `mcp.json` in the user folder and a trusted project folder (`tools::mcp::config::load`, read in `load_settings`; a later layer's server of the same name wins; servers sorted by name): `{"servers": {"<name>": {"command","args","env"} or {"url","headers"}, "enabled" (true), "alwaysLoad" (false), "timeoutMs" (120000)}}`; names `[A-Za-z0-9_-]+`; `env` and `headers` values expand `${VAR}` only when a server starts, and `doctor`/`mcp list` print names, never values. Own client, no crate: stdio (JSON-RPC lines, non-JSON lines skipped, stderr dropped, the tree in one `ProcessGroup`) and Streamable HTTP (POST, JSON or SSE body; `MCP-Protocol-Version`, `Mcp-Method`, `Mcp-Name`, `Mcp-Param-*` from `x-mcp-header`, base64 sentinel for unsafe values). Era: `server/discover` with the 2026-07-28 `_meta` first (stateless, every request carries `io.modelcontextprotocol/protocolVersion`, `clientInfo`, `clientCapabilities`); a result or a modern error (-32020/-32021/-32022 still listing 2026-07-28) is modern; any other error, a non-JSON 4xx or 10 s of silence falls back to `initialize` (2025-11-25) plus `notifications/initialized`, with `Mcp-Session-Id` and the agreed version on HTTP. No server starts with a session: `Extensions` (`tools::mcp::McpServers`) indexes `<home>/mcp-cache/<server>.json` (`{version:1, server, fingerprint (FNV-1a of command+args or url), fetchedAt, ttlMs, cacheScope, era, tools}`; no `ttlMs`: 1 h); `fast-harness mcp refresh [SERVER]` fills it, `fast-harness mcp list` and `doctor` show servers, cache age and tool counts; a server without a cache adds no tools. The first call of a server's tool starts it, refreshes a list past its `ttlMs` first, then sends `tools/call`; a server stops after 10 idle minutes (a reaper thread holding a weak handle, plus a check on every call) and when the settings are reloaded or the process ends (job object). Names `mcp__<server>__<tool>`, characters outside `[A-Za-z0-9_-]` become `_`, over 64 characters cut with an FNV hash; descriptions cut to 1 KB; results: text blocks joined, image, audio, binary resources and links as one-line notes, `structuredContent` when no content, `isError` an error; the D37 budget applies. Wire: servers in name order join the session's tool list as deferred tools while the totals stay within 64 tools and 64 KB of definitions; from the first server that does not fit, the tools stay out and two deferred tools `mcp_describe(name)` and `mcp_call(name, arguments)` reach any indexed tool, `find_tools` matches those tools by `names` or `query`, lists them after its tool lines and loads both helpers; the list is frozen with the session (D36), so every provider sees the same size. `alwaysLoad` preloads a server's tools (or the two helpers) like `tools.preload`. Hooks see `mcp__*` names (through `mcp_call` the name is `mcp_call`). Specs: [changelog](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/docs/specification/2026-07-28/changelog.mdx), [versioning](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning), [discover](https://modelcontextprotocol.io/specification/2026-07-28/server/discover), [Streamable HTTP](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http).
