# D20: Icons

Nerd Fonts v3.5.1 (owner: "sử dụng nerdfont"). GUI: an embedded 60-glyph subset of Symbols Nerd Font renamed "Fast Harness Icons" (`crates/fast-harness-gui/fonts/`, with the Nerd Fonts licence and notes on the glyph sets: Codicons, Material Design Icons, Octicons); code points live in `ui/icons.slint`. TUI: glyphs from the terminal's Nerd Font, `"icons": "plain"` or `FAST_HARNESS_ICONS=plain` for a terminal without one; every glyph is one cell wide (never U+26A1).
