# D30: Find tool

Owner, 2026-11-12: "find tool cho harness, tool không bao giờ load ở ngay từ đầu". Every session and subagent starts with one loaded tool, `find_tools`, whose description names the other tools (read, write, edit, shell, grep, glob, subagent) without their schemas. Input `query` (words matched against names, descriptions and parameter names) or `names` (exact names); at most 5 tools per call. Claude: every other tool is sent with `defer_loading: true` and `find_tools` answers with `tool_reference` blocks, so the tools array never changes and the prompt cache holds. Antigravity: a found tool joins `functionDeclarations` from the next request (one cache miss per find). The found set is rebuilt from the conversation on resume. A call to a tool not found yet returns an error telling the model to find it first.
