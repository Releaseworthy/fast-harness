# D74 GUI subagents: a pill, a popover and a read-only child view

Status: done (2026-11-14).

## Decision

The inline "Subagent <id> ..." notes leave the GUI transcript (the TUI keeps them): `turn.rs` `deliver` hands every `Subagent` and `SubagentProgress` event to `subagents_view::event` first, the one place that filters (`subagents_view::take`, tested). A pill sits left of the jobs pill (D72) in one row above the composer (`ui/subagents.slint` `PillsRow`; both pills are `ui/pill.slint` `Pill`, both popovers `PopoverCard`): "N subagents running" while any runs, else "N subagents", hidden without subagents.

The popover lists each child: state mark and word (running, finished, failed, or stopped with cancelled, paused or interrupted), its label (the `subagent` call's `description`, else its first prompt), `step N · tool`, and how long a finished one ran. Escape or a click outside closes it. Nested children are reached from the child's own view (its pill lists its children).

## Source of the list

Core `session::children(home, cwd, parent)` (`session/children.rs`) reads the first line of every log in the folder and keeps those whose header names the parent, with the last turn's step, tool and outcome; the label comes from the parent's log (the `tool/result` of the `subagent` call names the child's session id). A worker runs it after each switch and at each subagent start or end; the live events give the running state and the latest step. Child sessions still show in the sidebar (not changed here).

## Read-only view

A row click opens the child session in the chat view (`App::open_session`; a running parent turn is parked, as any switch). While it shows, the composer and the undo row give way to "Subagent session, read-only" with "Back to <label or 'parent session'>" (also Escape). A running child is not mirrored live: its log opens again on each of its events (`open_load::reload`, at most every 500 ms), which keeps the same service session.

## State

`SubagentsUi` global (`ui/subagent_row.slint`); `MainWindow` properties do not change.
