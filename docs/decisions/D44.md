# D44: Hooks

Owner, 2026-11-12: "tao muốn mọi thứ đều custom và chỉnh sửa được" (docs/efficiency-plan.md phase 17B part 1, `docs/extending.md`). `hooks.json` in the user folder and a trusted project folder (`tools::hooks::Hooks::load`, read with the settings in `load_settings`, kept in `Extensions::hooks`; both files run, user entries first; no file: one failed read per folder and no process ever spawned): `{"<Event>": [{"match", "command", "args", "timeoutMs"}]}` for `SessionStart`, `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PreCompact`, `Stop`, `SubagentStop`; an unknown event name skips the file (reported). `match` (tool events only): `|` alternatives of globs with `*` and `?`, absent matches all. A hook (`tools::hooks::run`) gets on stdin `{event, sessionId, cwd}` plus the event data (`prompt`; `source`; `toolName`, `arguments`; `output`, `isError`; `trigger`, `instructions`, `summaryRequest`; `answer`, `stopHookActive`), runs in cwd in one `ProcessGroup` (default timeout 60 s, killed on timeout or cancel), and answers on stdout (empty: no-op) with a JSON object: `decision: block` + `reason` (tool call: error result `blocked by a hook: <reason>`; prompt: the turn does not run, outcome `Failed`, an `Error` event shows the reason, nothing is sent or added; PreCompact: no compaction; Stop: the reason is the next user text; later hooks of the event are skipped), `arguments` (PreToolUse: the tool runs with them, the logged call stays as the model sent it), `output` (PostToolUse: replaces the output before the D37 budget and the first send, through `Registry::run_with`), `context` (kept in `Turn::hook_context`, added as `[hook context] <text>` with `kind: "hook"` at the tail just before the next model call, after the last tool results or user text; PreCompact context joins the summary instructions), `continue` (Stop: the turn goes on with it as a user message; bounded by `maxSteps`). `SubagentStop` replaces `Stop` in a session with `depth` above 0 (`Conversation::depth`). Tool hooks run on the tool threads (`agent::hooks::run_tool`), their records traced by the turn thread. Fail open: a start failure, timeout, non-zero exit or an answer that is not a JSON object is traced `hook/error`, sent as an `Error` note and ignored. Trace version 10: `hook {turn, event, command, ms, decision}`. `doctor` lists hooks (event, pattern, command, layer, timeout). Tests: `tests/hooks_tools.rs`, `tests/hooks_points.rs`.
