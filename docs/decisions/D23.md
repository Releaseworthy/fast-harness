# D23: Google Antigravity accounts

**Moved to branch `antigravity` (D53), not on main.** Owner, 2026-11-12: "accounts thì thêm google antigravity nữa". Google sign-in in the browser with Antigravity's OAuth client (PKCE, loopback callback), refreshed by Fast Harness; project from `loadCodeAssist` (or `onboardUser`); quota from `retrieveUserQuotaSummary` (groups "Gemini Models" and "Claude and GPT models", each with a 5 h and a weekly window); models from `fetchAvailableModels`: every model the account lists (Gemini, Claude, GPT-OSS). Requests follow the live-verified DSH antigravity-switch port: identity text first, Hub User-Agent, daily host then sandbox on 404, 408, 5xx or a network error, cleaned tool schemas, sanitised tool names, thought signatures carried, `VALIDATED` tool mode for Claude, `finishReason: OTHER` after a call read as a stop. Auto switch only among Google accounts (hold until the group's reset, then the account with the most quota left); a provider never switches by itself. Quota is polled only while a front end is open, at most every 10 minutes per account and 30 s or more after a turn.
