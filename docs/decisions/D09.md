# D9: Token storage

`accounts.json`, secrets encrypted with DPAPI on Windows. Secrets are never stored in plaintext: off Windows `platform::protect` stays `Unsupported`, so accounts with stored secrets (Claude sign-in and API keys added to the pool, Google accounts, the encrypted Google OAuth client file) are Windows only, and the tests that need them are ignored there. On Linux and macOS use `providers/*.json` entries with `keyEnv` (D41) or the `FAST_HARNESS_GOOGLE_CLIENT_ID`/`_SECRET` variables. Random bytes (PKCE verifier, OAuth state) come from BCryptGenRandom on Windows and `/dev/urandom` on Unix.
